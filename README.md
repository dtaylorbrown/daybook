# DayBook

DayBook is a daily planner for busy people. It brings your todos, habit tracking, notes and calendar together in one place.

It is a web application with a React frontend and a FastAPI backend.

## Project outline

```
daybook/
├── backend/        # FastAPI API (Python)
│   └── app/
│       └── main.py # API entry point
├── frontend/       # React + TypeScript app, built with Vite
│   └── src/
└── docs/           # Project documentation
```

### Tech stack

- **Frontend:** React 19, TypeScript, Vite, ESLint
- **Backend:** Python, FastAPI
